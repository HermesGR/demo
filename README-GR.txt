SORBETTOGAMES 1.0.4 — ΕΜΦΑΝΙΣΗ / ΦΙΛΤΡΑ

Εγκατάσταση δοκιμής: plugin.program.sorbetto.games-1.0.4.zip, επάνω στην προηγούμενη έκδοση, χωρίς διαγραφή δεδομένων. Πρώτος στόχος Windows 64-bit / Kodi 21.3. Δεν εκτελέστηκε σε πραγματικό Kodi. Ο έλεγχος περιλαμβάνει σύνταξη, πακέτα, μεταδεδομένα και προσομοιωμένη λειτουργία UI.

ΑΛΛΑΓΕΣ
1. Νέο σκοτεινό οριζόντιο tech background 1920x1080, χωρίς τον μοχλό, με διακριτικό πλέγμα/γραμμές και σκοτεινή περιοχή λίστας. Χρησιμοποιείται τόσο ως addon fanart όσο και στα εσωτερικά μενού.
2. Νέο εικονίδιο 1024x1024: αφαιρέθηκαν οι μεγάλες εξωτερικές μαύρες λωρίδες από την αρχική φωτογραφία, διατηρείται ολόκληρος ο μοχλός με ασφαλή περιθώρια. Νέα paths εικόνων, ώστε να μην παραπέμπουν στις προηγούμενες cached εκδόσεις.
3. Απευθείας λίστα 15 παιχνιδιών, χωρίς αρχική επιλογή κονσόλας. PS1 πρώτα, μετά SNES, Mega Drive, Arcade.
4. Κουμπί «Κονσόλα: Όλες» στην κορυφή. Φίλτρα Όλες / PlayStation 1 / Nintendo — Super Nintendo / Sega — Mega Drive / Arcade. Το φίλτρο επανέρχεται σε Όλες σε κάθε νέο άνοιγμα.
5. Κάθε καταχώριση δείχνει κονσόλα και κατάσταση εγκατάστασης/διαθεσιμότητας. Κουμπιά Ανανέωση Release / Εικόνες παιχνιδιών / Ρυθμίσεις / Κλείσιμο.

ΠΛΟΗΓΗΣΗ
Ποντίκι: κουμπιά επάνω και επιλογή παιχνιδιού στη λίστα. Πληκτρολόγιο/χειριστήριο: επάνω στην πρώτη γραμμή ή αριστερά για τα φίλτρα, δεξιά/αριστερά μεταξύ κουμπιών, κάτω για τη λίστα, Enter επιλογή, Esc επιστροφή.

ΔΙΑΤΗΡΟΥΝΤΑΙ
Τα IDs και οι φάκελοι των εγκατεστημένων παιχνιδιών 1.0.1–1.0.3. Η λήψη και εκκίνηση μέσω Kodi RetroPlayer. Υποχρεωτικές εξαρτήσεις: PCSX ReARMed, Snes9x, Genesis Plus GX, FinalBurn Neo, μέσω επίσημου Kodi Add-on repository. Δεν απαιτείται εξωτερικό RetroArch. Τα binaries των cores δεν περιέχονται στο ZIP. Απαιτείται Internet για εξαρτήσεις/παιχνίδια/online εικόνες και τυχόν έγκριση Kodi.
Οι εικόνες παιχνιδιών παραμένουν online από Libretro, με χειροκίνητη εντολή λήψης/cache. Δεν έχουν επιβεβαιωθεί και οι 15 και δεν περιλαμβάνονται ανεξάρτητα λογότυπα. Τα γενικά παράθυρα ρυθμίσεων/μηνυμάτων ελέγχονται από το ενεργό skin του Kodi.
Δεν περιέχονται ROMs ή BIOS. Το PS1 μπορεί να απαιτεί νόμιμο BIOS. Arcade: εξωτερικό asset ZIP πρέπει να περιέχει αυθεντικό ZIP ROM set χωρίς μετονομασία, συμβατό με FinalBurn Neo· BIOS/parent sets δεν επιλύονται αυτόματα.

ΔΗΜΟΣΙΕΥΣΗ ΑΦΟΥ ΔΟΚΙΜΑΣΤΕΙ
Δύο ZIP εγκατάστασης στο υπάρχον Release μαζί με το crash.zip. Τα περιεχόμενα του Pages ZIP δημοσιεύονται στη σωστή πηγή GitHub Pages με διατήρηση των υποφακέλων. Η απλή προσθήκη του συμπιεσμένου Pages ZIP σε Release δεν ενημερώνει το feed. Κράτησε τα προηγούμενα ZIP για επιστροφή.
