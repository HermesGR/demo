Elite Basketball Manager 0.2.0
Upload ZIP in WordPress Plugins > Add New > Upload; replace previous version and activate.
Admin menu: Elite Basketball > Open game. Page is created automatically.
No external services, libraries, fonts or assets. Fictional clubs and players.
Demo only: friendly match, no accounts, season storage or multiplayer.
Graphics: Canvas perspective court, stylized figures, crowd, ball and shot arc.
Audio: optional synthesized event tones only (not recorded arena sound).
Coaching: pace, shot focus, plays, star, rebounding, pressure, traps, zones,
PnR coverage, priority defender, contact aggression, one-possession commands.
Simplifications: side trap shares handler model; inbound pressure uses full press;
no full defensive matchup mapping; substitutions at possession boundaries;
timeouts simplified; game clock runs through free throws in this demo.
Figures use scripted phase positions, not physical player intelligence.
Not browser- or WordPress-runtime tested. Test on staging first.
